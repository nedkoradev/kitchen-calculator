# v1.68 — лицеви посоки и безопасен преглед на снимки

## Фладер

Секцията в Свойства на детайла → Материал се показва само за материал с grainRequired. Стойността остава **единствено** finish.grainAxis. `grainFaceOptions()` дава разбираеми лицеви направления: ширина/височина за вертикална плоскост и ширина/дълбочина за хоризонтална, с действителните размери. Дебелината никога не е избор. Глобалната ос е вътрешната стойност, не втори UI модел.

Ротацията използва съществуващото x↔z/y правило. Преместването не променя фладера. Материалната смяна запазва приложимата finish стойност; при материал без посока контролът се скрива. Избраният отделен детайл има двупосочна линия по физическия фладер в 2D/3D, включително без texture URL. Тя е само selection overlay, не моделна геометрия и не променя кантовете. Общият cutLayout остава източникът за разкрой/Salex.

## Локален файл не е качен файл

`material-photo-editor.mjs` управлява локалния преглед отделно от материалния запис. Бутонът „Избери снимка“ приема JPG/PNG/WebP до 10 MiB; проверяват се extension/MIME, действителен header и browser image decode. Ограничението за декодирана снимка е 8192 px на страна и 16 мегапиксела. Предварителният преглед е временен blob URL, използван само от IMG в редактора.

Показват се оригинално име, байтове/MiB, пикселни размери и безопасно предложено име/път под materials/textures/. Името съдържа кратък SHA-256 отпечатък, за да не се подменя неволно използван декор. „Копирай пътя“ копира относителния адрес (с Ctrl+C fallback). Снимката трябва да бъде публикувана отделно чрез GitHub/Codex, през проверен клон/PR. Приложението няма GitHub token, API upload, Firebase Storage или Supabase Storage.

„Провери снимката в GitHub“ извършва публичен HTTP GET без credentials и browser cache, проверява успех, image MIME, размер, signature и действително декодиране. HTTP 200 HTML не е успех. При локално избран файл remote bytes трябва да имат същия пълен hash. HTTPS адресите и безопасните относителни Pages адреси се поддържат. Добавя се само временен query nonce за проверката; той не се записва в материала. PWA изрично пропуска тези заявки, за да не се потвърждава снимка от offline fallback.

В material.textureUrl се записва само провереният публичен URL, при натискане на „Запази“. Непроверен нов адрес не заменя стария: „Запази“ запазва останалите настройки с предишната снимка. Изричното „Премахни снимката“ изчиства URL при save. Реалните textureWidthMm/textureHeightMm не се заменят с пикселните размери и остават при замяна/премахване.

Blob/data/Base64/File не се записват в каталога, localStorage, snapshot или Firebase. При cancel/close се прекратяват HTTP заявки, отхвърлят се закъснели async резултати и се освобождават blob URL-ите. Записаната снимка не се променя от preview/проверката преди Save. Новите материали без потвърдена снимка могат да се запазят без texture URL.
