# Снимки на материални декори

Добавяйте тук JPG, JPEG, PNG или WebP чрез проверен Git клон/PR. Не е нужен токен в браузъра и приложението не качва файлове към GitHub.

В материалния редактор използвайте `materials/textures/ime-na-dekora.webp` (или `./materials/textures/...`). Пътят се запазва относителен и работи под GitHub Pages `/kitchen-calculator/`. Използвайте устойчиви имена; не изтривайте/преименувайте използван файл, без да обновите препратките в материалите и съществуващите записи. Препоръчителни са малки оптимизирани изображения и снимки с вертикален фладер. Не поставяйте секретни или лични данни в публичното хранилище.

Настройки показва общите байтове на текущите изходни файлове и на тази папка. README също участва в размера на папката; броят снимки включва само JPG/JPEG/PNG/WebP (включително подпапки). Git историята, игнорираните файлове и GitHub физическият disk usage не се измерват.
